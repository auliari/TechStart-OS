# Project Remastering Linux - TechStart OS

Project ini berisi kumpulan skrip perintah dan konfigurasi untuk melakukan remastering sistem operasi Linux berbasis **Ubuntu 26.04** untuk memenuhi tugas mata kuliah **Sistem Operasi**.

## 🛠️ Fitur & Kustomisasi yang Dilakukan
- **Tampilan:** Mengubah tema desktop environment, ikon, wallpaper, boot splash, dan layar login.
- **Aplikasi Programming & Tools:** Visual Studio Code, Geany, GCC/G++, Python 3, PHP, Git, Flutter SDK, Android Studio, dan Qt Creator.
- **Aplikasi Produktivitas & Desain:** Firefox, LibreOffice, GIMP, Figma (web shortcut), TechaGuide, Sikadu, dan Elena.
- **Pembersihan Bloatware:** Menghapus `aisleriot`, `gnome-mahjongg`, `gnome-mines`, `gnome-sudoku`, `rhythmbox`, `transmission-gtk`, `remmina`, dan `simple-scan`.
